# Contributing

Thanks for taking a look at my projects.

## Pull requests

Keep changes focused and explain the problem they solve. Include verification steps when the change affects behavior, builds, or configuration.

Before opening a PR:

- run the relevant tests or checks;
- keep secrets and local configuration out of commits;
- update documentation when behavior or setup changes;
- avoid unrelated formatting churn.

For UI changes, screenshots are welcome when they make the result easier to review.
